# Personal Information Hub

מרכז מידע אישי בעברית שמחבר בין Supabase ל־Google Drive ומאפשר לנהל פרויקטים, משימות, מסמכים ואזורי מידע במקום אחד.

## המוצר

- התחברות מאובטחת באמצעות Supabase Auth
- הצגת קבצים אמיתיים מ־Google Drive בהרשאת קריאה בלבד
- ניתוח וסינון מסמכים לצורך עשיית סדר
- אזורי מידע אישיים ושיוך פנימי בטוח של מסמכים
- פרויקטים, משימות ופעולות המשך
- ממשק עברי מלא ב־RTL

היישום נמצא בתיקייה `prototype-v2`. הוראות ההפעלה והפריסה נמצאות ב־`prototype-v2/DEPLOYMENT.md`.

## אבטחה

סודות אינם נשמרים במאגר. יש להגדיר אותם באמצעות משתני סביבה לפי `.env.product.example`.
